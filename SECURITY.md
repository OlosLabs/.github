# Security Policy

Olos Labs takes the security of its software products, autonomous systems, and digital infrastructure seriously. We appreciate responsible security research and vulnerability reports disclosed in good faith.

---

## Reporting a Vulnerability

**Do not report security vulnerabilities through public GitHub issues or discussions.**

Send all reports directly via email:
* **Primary:** `security@oloslabs.com`
* **Fallback:** `contact@oloslabs.com`

### Report Requirements

To help us verify and triage the finding efficiently, please include:
1. Target repository, commit hash, or deployed endpoint.
2. Vulnerability classification and estimated severity.
3. Minimal, reproducible Proof of Concept (PoC) or exact reproduction steps.
4. Description of potential impact and exploitation scenario.

---

## Response Timeline

* **Acknowledgment:** We aim to acknowledge receipt of valid reports within **48 hours**.
* **Remediation:** We will keep you informed of triage status, validation, and expected fix timelines.
* **Disclosure:** We practice coordinated vulnerability disclosure once fixes are deployed.

---

## Safe Harbor

We consider security research conducted under this policy to be authorized. We will not pursue legal action against researchers who:
* Act in good faith to prevent privacy violations, data destruction, or interruption of services.
* Refrain from social engineering, phishing, or physical attacks against Olos Labs personnel.
* Avoid high-volume automated testing (DDoS, volumetric brute-force) against live production infrastructure.
* Allow reasonable time to remediate before disclosing details publicly.
